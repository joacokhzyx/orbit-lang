# Security Policy

## Supported Versions

Security updates are applied to the latest release of Orbit.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

---

## Reporting a Vulnerability

Security reports for the compiler, runtime and Kynx are handled privately. Do not open a public issue.

### Disclosure Process

1. **Email findings**: send details to `security@orbit-lang.org`.
2. **Provide details**: include reproduction steps, sample `.orb` code, OS details, and potential impact.
3. **Response time**: a report is acknowledged quickly and patch status is kept current. Orbit is maintained by one person, so a weekend can delay a reply. Reports are not left unread.
4. **Coordinated disclosure**: please keep it confidential until a fix or advisory is out.

Thanks for helping keep Orbit secure. Every report is read.
